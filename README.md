# speech-studio

Кабинет речи. Приложение для ведения расписания занятий логопеда с возможностями ведения отчетности по занятиям.

## Структура проекта

Монокрепозиторий: спецификации разрабатываются на уровне репозитория, а реализация вынесена в подкаталог `src/`.

```
speech-studio/
├── openspec/               # OpenSpec-спецификации всего проекта
│   ├── config.yaml         # Настройки и контекст OpenSpec
│   ├── specs/              # Актуальные спецификации функций (add-child, create-lesson, persist-lessons и др.)
│   └── changes/            # Незавершённые и архивные изменения
├── src/
│   └── slt-mobile/         # Мобильное приложение (Android, Kotlin, Jetpack Compose)
└── README.md
```

## Проекты

### slt-mobile

Мобильное приложение для Android: Kotlin, Jetpack Compose, офлайн-first работа. Расположено в `src/slt-mobile/`. Собственный README и архитектурные документы — внутри модуля.

## Спецификации

Спецификации проекта ведутся в OpenSpec и находятся в корне репозитория: `openspec/`.

- `openspec/specs/` — актуальные спецификации функций.
- `openspec/changes/` — предложенные и находящиеся в работе изменения.
- `openspec/config.yaml` — настройки и контекст для работы с OpenSpec.
