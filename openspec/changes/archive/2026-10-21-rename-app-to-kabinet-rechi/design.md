## Context

Мотивация и границы — в [proposal.md](proposal.md); контракт — в [app-identity](specs/app-identity/spec.md).

Найденная цепочка: Android `AndroidManifest.xml` (application и activity) → `@string/app_name` → `app/src/main/res/values/strings.xml`; iOS → `INFOPLIST_KEY_CFBundleDisplayName` в двух конфигурациях `project.pbxproj`; общий `App` → `AppDrawer` → составной заголовок «Логопед» + «+», `contentDescription` и fallback «Л+». Старое имя встроено и в общий `icon1024.png`, и в Android launcher foreground WebP; одной замены строк недостаточно. В `iosApp` каталога иконок сейчас нет.

Фактически код уже разделён на `app`, `shared` и `iosApp` в незавершённом изменении `cross-platform-kmp`. Указанный в AGENTS.md `openspec/README.md` отсутствует; проверены конфигурация OpenSpec и действующая спецификация `app-navigation`, которая не задаёт имя продукта.

## Goals / Non-Goals

**Goals:** согласовать платформенные метки, общий UI и графику с новым именем; сделать длинный заголовок читаемым; обеспечить совместимость обновления.

**Non-Goals:** смена package/идентификаторов, новая схема хранения, переработка навигации, завершение KMP-приёмки или публикация в магазинах.

## Decisions

1. **Менять отображаемые имена, сохраняя технические идентификаторы.** Android `applicationId`/`namespace` — `com.logoped_plus`, iOS bundle id — `com.logopedplus.iosApp`. Сохраняются Kotlin package, имена классов/тем, Gradle rootProject, ключи подписи, файл БД и ключи настроек. Альтернатива с массовым техническим переименованием увеличивает риск новой установки и не требуется для пользовательского названия.

2. **Обновить существующие точки отображения.** В Android изменить `app_name`, в iOS — обе настройки display name. В общем меню заменить составной заголовок одной строкой «Кабинет речи» с допустимым переносом по словам, обновить описание и fallback «КР». Сохранить подзаголовок меню. Новая инфраструктура локализации ради одной смены названия не нужна; альтернативу с отдельными платформенными меню отклоняем, поскольку UI общий.

3. **Подготовить согласованную графику.** Сохранить мотив ребёнка, речевого облака и ростка; для маленьких launcher-иконок использовать знак без мелкой надписи, для изображения меню также допустим знак без текста: полное имя уже находится рядом. Обновить обе копии `icon1024.png`, Android mipmap-иконки всех плотностей, round/foreground и их адаптивное использование; просмотреть обычный и monochrome варианты. Альтернатива с сохранением старого растра оставляет старое имя видимым. Создание нового iOS asset catalog относится к готовности iOS-оболочки и не требуется для замены отсутствующего ресурса.

4. **Актуализировать текущие продуктовые описания адресно.** Заменить имя в архитектуре, карте пакетов, iOS README, актуальном описании продукта и строке контекста OpenSpec. Архивы, отчёты и мотивировку существующих изменений не переписывать. Не выполнять глобальную замену `LogopedPlus` или `com.logoped_plus`.

5. **Минимальные проверки.** Осмотр строк, конфигураций и графики; поиск остатков старого пользовательского имени с исключением build/IDE/истории; `git diff --check`. После изменения UI/ресурсов — `:app:assembleDebug`, проверка метки в собранном APK и merged manifest. Новые unit-тесты на константы не нужны. Сохранность установки проверяется неизменностью идентификаторов и контрактов хранения в diff: миграция данных отсутствует. Запуски и установки на эмулятор запрещены текущим `openspec/config.yaml`; фактическую проверку обновления, TalkBack/VoiceOver и увеличенного текста фиксировать как открытую до доступной ручной приёмки. Xcode-сборка и просмотр имени iOS доступны на macOS; на Windows проверить обе конфигурации статически.

Архитектурное соответствие: применимы разделы 4.1, 16, 23 и 26 `ARCHITECTURE.md`. Затронуты Presentation, платформенные метаданные и ресурсы; domain/data и offline-first контракты сохраняются. Новые слои и зависимости не требуются, отклонений нет.

6. **Имя репозитория — `speech-studio`.** Текущий `origin` — `https://github.com/gorser96/slt-plus.git`. Переименовать существующий репозиторий на GitHub, затем обновить `origin` на `https://github.com/gorser96/speech-studio.git`. Проверить актуальные ссылки и автоматизацию на привязку к `gorser96/slt-plus`, заменить их на новый адрес. Сохранить историю и настройки существующего репозитория; перенос в новый репозиторий не требуется. Локальную папку `D:\projects\slt-plus` можно сохранить: её имя не определяет имя репозитория. Gradle rootProject, package и платформенные идентификаторы сохраняются согласно решению 1. Критерии `app-identity` остаются прежними: имя репозитория относится к организации разработки.

## Risks / Trade-offs

- [Старое имя остаётся внутри изображения] → просмотреть растры и все реально используемые launcher-варианты, а не только искать текст.
- [Новое имя длиннее] → разрешить перенос, проверить ограничения ширины и увеличенного текста; неподтверждённую визуальную приёмку оставить открытой.
- [Случайная смена идентичности установки] → проверить diff идентификаторов, подписи, БД и настроек; не переименовывать внутренние символы автоматически.
- [Расхождение с карточкой магазина] → при публикации отдельно выставить «Кабинет речи» в Play Console; изменение репозитория само не обновляет карточку.

## Migration Plan

Выпустить обычное обновление с прежними идентификаторами и подписью; номера версий определяются процедурой выпуска. Миграции данных не нужны. Откат оформления выполняется обратной заменой строк и ресурсов в следующем совместимом обновлении без очистки данных.

Переименование GitHub выполнять при реализации после проверки доступности `gorser96/speech-studio` и прав текущего аккаунта. Результат проверить по имени репозитория через GitHub API, `git remote -v` и `git ls-remote origin HEAD`. При недоступных правах зафиксировать блокер. При необходимости отката вернуть прежнее имя через настройки GitHub и восстановить `origin`.
