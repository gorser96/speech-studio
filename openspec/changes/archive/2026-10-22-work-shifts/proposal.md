## Why

Специалист работает в детском саду сменами: дети приходят по очереди, их состав и длительность меняются, а видео снимаются отдельно по каждому ребёнку. Сейчас «групповое занятие» означает одновременное присутствие детей и не выражает длинный рабочий период, а видео приходится искать и прикреплять отдельно для каждого занятия. Нужна смена как контейнер индивидуальных занятий и явный тип группового занятия.

## What Changes

- Появляется «рабочая смена»: окно времени, базовая длительность, перерыв и упорядоченные слоты. Шаблон смены хранит только сетку времени и дни повторения, без состава детей.
- Смена заполняется вручную: ребёнок выбирается из списка или создаётся по имени на месте, порядок меняется перетаскиванием, длительность слота корректируется.
- По кнопке создаются индивидуальные занятия для заполненных слотов; по второй кнопке выполняется пакетный поиск видео по занятиям смены с подтверждением.
- Вводится явный тип занятия: индивидуальное — ровно один ребёнок, групповое — двое и более одновременно. Групповое занятие создаётся отдельно и не входит в смену.
- Смена отображается в расписании как контейнер, отличимый от группового занятия.
- Новые данные сохраняются в Room с миграцией v4 → v5; создание занятий смены атомарно.

## Capabilities

### New Capabilities

- `work-shifts`: шаблон и экземпляр смены, слоты, быстрое заполнение, создание занятий, пакетный поиск видео.

### Modified Capabilities

- `create-lesson`: явный выбор типа, групповое занятие отдельным действием, ограничения участников по типу, запуск создания из верхней строки.
- `edit-lesson`: тип занятия сохраняется при изменении параметров и участников.
- `browse-schedule`: подпись типа берётся из сохранённого типа; смена показывается отдельным контейнером.
- `persist-lessons`: новые таблицы шаблонов, смен и слотов, поля типа и связи занятия со сменой, миграция v4 → v5, атомарность создания смены.
- `lesson-videos`: пакетный поиск видео по смене и подтверждение сопоставления.

## Impact

- Domain: `LessonType`, `WorkShift`, `ShiftTemplate`, `ShiftSlot`, правила расчёта сетки и сопоставления видео.
- Data: Room v4 → v5, DAO и repository смен, транзакционное создание занятий, существующие занятия получают тип по числу участников.
- UI: расписание, экран смены, выбор ребёнка с быстрым созданием, разбор видео; Android-поиск видео остаётся за существующим `VideoCapabilities`.
- Новые ML-модели, сеть и сервер не добавляются. Превью видео использует системные средства Android.
- Проверки: чистый расчёт сетки и сопоставления видео, миграция Room, адресные сценарии UI. Эмулятор и connected-тесты по действующему ограничению проекта не запускаются.
