# com.logoped_plus.ui

Общая оболочка приложения, боковое меню и идентификаторы разделов. [Общий указатель](../../../../../../../PACKAGES.md).

| Файл | Назначение |
|---|---|
| [App.kt](App.kt) | `App` — общая для Android и iOS оболочка: Drawer, TopAppBar, пять разделов, сохранение раздела, подтверждение выхода (`onExit`), экранное действие «Назад» (`showSectionBack`), перехват системного Back через `PlatformBackHandler`; логотип по умолчанию — общий ресурс `composeResources/drawable/icon1024.png`, параметр `logo` позволяет подменить; принимает `ShiftViewModel` и `ShiftTemplatesViewModel` и показывает экран смены при `openShiftId`, а в режиме смены — иконку удаления в `actions` |
| [AppDrawer.kt](AppDrawer.kt) | Пять пунктов (Расписание, Дети, Шаблоны смен, Тэги, Настройки): выделение раздела, enabled, семантика disabled и guard callback; логотип передаётся как `Painter?` |
| [AppScreen.kt](AppScreen.kt) | Schedule, Children, ShiftTemplates, Tags, Settings |

Навигацией владеет [App](App.kt). Во время busy (запись/генерация/удаление любого экрана, включая `shiftState.working` и `shiftTemplatesState.working`) недоступны открытые пункты drawer; App отдельно проверяет актуальный статус, блокирует кнопку меню, жесты и Back. Вложенные экраны (карточка/редактор, экран смены, диалоги) перехватывают Back раньше. Navigation Compose не внедрён.

В корне расписания `TopAppBar.actions` содержит иконку «+» с выпадающим меню («Индивидуальное занятие», «Групповое занятие», «Смена»); кнопка доступна при загрузке/ошибке чтения и прокрутке, скрыта при открытом lesson editor или смене (`openShiftId != null`) и заблокирована при общем busy. В режиме смены заголовок бара переключается на «Смена», навигационная иконка меняется на стрелку «К расписанию», а в `actions` показывается иконка удаления смены (подтверждение — в диалоге `ShiftScreen`). Раздел «Шаблоны смен» открывается из меню под «Дети» и показывает одноимённый заголовок.

Android-оболочка передаёт `activity.finish()` как `onExit` и оставляет `showSectionBack = false` (системная кнопка уже работает). На iOS `onExit = null`, `PlatformBackHandler` — no-op, поэтому подтверждение выхода недостижимо, а возврат между разделами выполняет экранная стрелка при `showSectionBack = true`.

## Проверки

На диске тестов оболочки нет; навигация проверялась осмотром кода. Сборка Android и адресные ViewModel-тесты выполнялись в изменении `cross-platform-kmp`; iOS-возвраты на macOS не проверялись — [статус проверок](../../../../../../../../../openspec/verification/README.md).
