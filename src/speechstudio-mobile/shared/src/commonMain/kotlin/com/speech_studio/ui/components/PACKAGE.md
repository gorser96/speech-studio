# com.logoped_plus.ui.components

Единые контролы ввода и общие элементы оформления Bento. [Общий указатель](../../../../../../../../PACKAGES.md).

| Файл | Назначение |
|---|---|
| [BentoComponents.kt](BentoComponents.kt) | Плоская карточка `BentoCard` (16 dp, белая surface, волосяная граница, без тени; вариант с `onClick` и `enabled`), плитка сводки `BentoStatTile`, микро-заголовок `SectionLabel` (капс, увеличенный трекинг) и `bentoTextFieldColors()` для полей ввода |
| [TimeField.kt](TimeField.kt) | Поле времени «ЧЧ:ММ»: только цифры (до 4) с автоформатом (3 цифры — «dd:d», если первые две ≤ 23, иначе «d:dd»), числовая клавиатура, выделение всего значения при входе в фокус (повторное нажатие — курсор в точку нажатия), курсор в конец после принятого изменения, `isError` и поддерживающий текст при невалидном значении; `parseTimeText(text): LocalTime?` (regex `\d{1,2}:\d{2}`, часы 0–23, минуты 0–59) |
| [NumberField.kt](NumberField.kt) | Поле числа: только цифры (до `maxDigits`), числовая клавиатура, выделение всего значения при входе в фокус (повторное нажатие — курсор в точку нажатия), `isError`/`supportingText` передаёт вызывающий; `CompactNumberField` — тот же ввод в компактной рамке без плавающей подписи, с единицей измерения справа (для плотных строк списка) |

Контролы управляемые строкой на `OutlinedTextField`: набор нового значения заменяет старое целиком (выделение при входе в фокус, повторное нажатие — точечное редактирование в точке нажатия, курсор в конец после принятого изменения). Потребители — [экран настроек](../screen/PACKAGE.md) (начальный/конечный часы сетки), [формы занятия](../screen/schedule/PACKAGE.md) (время, длительность) и [строки шаблона карточки ребёнка](../screen/children/PACKAGE.md) (время, минуты). Пакет нейтрален к экранам, чтобы `children` не зависел от `schedule`.

`BentoCard`/`BentoStatTile`/`SectionLabel` используются всеми экранами и берут цвета, формы и типографику только из `MaterialTheme`; собственные радиусы, тени и цвета экраны не задают.

## Проверки

На диске тестов для пакета нет: поведение проверяется осмотром кода и unit-тестами потребителей (см. [статус проверок](../../../../../../../../../../openspec/verification/README.md)).
